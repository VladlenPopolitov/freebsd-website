Sylve — Унифицированная платформа управления системами для FreeBSD

Ссылки:
Веб-сайт URL: https://sylve.io
GitHub URL: https://github.com/AlchemillaHQ/Sylve
CI URL: https://sylve-ci.alchemilla.io
Discord URL: https://discord.gg/bJB826JvXK

Контактное лицо: Hayzam Sherif <hayzam@alchemilla.io>

Sylve — это современная унифицированная платформа управления системами для FreeBSD. Она предоставляет интегрированный веб-интерфейс для управления виртуальными машинами (через Bhyve), клетками (Jails), сетью вокруг них и хранилищем ZFS.

Бэкенд реализован на Go, а фронтенд построен на Svelte. Проект делает акцент на минимальном системном следе. По умолчанию ему не требуются никакие пакеты за пределами базовой системы.

Опциональные зависимости времени выполнения, необходимые только при использовании соответствующих функций, включают:

  • devel/libvirt для виртуализации

  • devel/qemu для управления образами дисков

  • net/samba419 для общего доступа к файлам по SMB

  • sysutils/swtpm для поддержки эмуляции TPM

  • dns/dnsmasq для служб DHCP и DNS

Порт подтягивает эти зависимости для удобства пользователя, но сам по себе Sylve не требует зависимостей для запуска.

Основные достижения во втором квартале

Дата-центр / Кластер

  • Реализованы способы для пользователей по организации высокодоступных виртуальных машин и клеток с автоматическим переключением на резервный/третичный и т.д. узел в кластере с помощью репликации ZFS (прямой миграции (live migration) пока нет).

  • Реализована возможность простой миграции виртуальных машин/клеток между узлами в кластере без кворума или высокой доступности (HA) с помощью простой кнопки «Migrate» в пользовательском интерфейсе.

  • Рабочие процессы резервного копирования и восстановления значительно улучшены: улучшена обработка ошибок и обратная связь с пользователем, включая поддержку зашифрованных наборов данных.

Сеть

  • Добавлена поддержка добавления сетевых маршрутов из веб-интерфейса.

  • Реализован межсетевой экран на основе PF с полной поддержкой правил трафика и NAT, включая возможность использования объектов в правилах для списков IP-адресов, FQDN и т.д.

  • Добавлена поддержка интуитивно понятного интерфейса конфигурации WireGuard, позволяющего пользователям легко настраивать и управлять туннелями WireGuard.

Хранилище

  • smart(8) включён в качестве зависимости как альтернатива smartmontools.

  • Управление пулами ZFS теперь поддерживает создание специальных VDEV.

  • Samba теперь использует встроенный mDNS-сервер вместо avahi.

  • Добавлена начальная поддержка iSCSI, позволяющая пользователям создавать и управлять iSCSI-целями и инициаторами непосредственно из веб-интерфейса.

Виртуальные машины и клетки

  • Улучшена отзывчивость и производительность пользовательского интерфейса, особенно для больших кластеров с большим количеством виртуальных машин/клеток.

  • Добавлена поддержка тегов VLAN для клеток напрямую, без необходимости создания отдельного моста для каждой VLAN.

  • Множество ручных флагов командной строки теперь преобразованы в синтаксис XML libvirt для виртуальных машин, что упрощает управление и улучшает совместимость с инструментами на основе libvirt.

  • Значительно улучшены процессы автоматического запуска/остановки виртуальных машин и клеток.

Общее

  • Переработана система уведомлений: добавлена поддержка веб-хуков Discord, ntfy.sh и транспортов на основе SMTP. Теперь она также поддерживает несколько транспортов одновременно и позволяет пользователям настраивать, для каких событий они хотят получать уведомления.

Обновление дорожной карты

  • Все пункты дорожной карты (кроме общих ресурсов NFS с предыдущего квартала) были выполнены, и теперь мы работаем над следующим набором функций для третьего квартала:

  • Поддержка общих ресурсов NFS, позволяющая пользователям создавать общие ресурсы NFS и управлять ими непосредственно из веб-интерфейса.

  • Упрощённый режим пользовательского интерфейса, призванный облегчить новым пользователям начало работы с Sylve в качестве NAS-устройства.

  • Поддержка Podman и контейнеров OCI, позволяющая пользователям запускать контейнеры вместе с виртуальными машинами и (классическими) клетками.

  • Мобильное приложение для iOS и Android, позволяющее пользователям управлять своими кластерами на ходу.

  • Библиотека шаблонов приложений, позволяющая пользователям легко разворачивать популярные приложения (такие как Nextcloud, Plex и т.д.) одним щелчком мыши.

Спонсоры: The FreeBSD Foundation, Alchemilla Ventures (разработка), IPTechnics LLC (инфраструктура и тестирование)

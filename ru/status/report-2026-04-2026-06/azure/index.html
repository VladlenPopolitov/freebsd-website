FreeBSD в Microsoft HyperV и Azure

Ссылки:
Статья о Microsoft Azure в вики FreeBSD URL: https://wiki.freebsd.org/MicrosoftAzure
Статья о Microsoft HyperV в вики FreeBSD URL: https://wiki.freebsd.org/HyperV

Контакт: Команда Microsoft FreeBSD Integration Services <bsdic@microsoft.com>
Контакт: Список рассылки freebsd-cloud
Контакт: Команда инженеров по выпуску релизов FreeBSD для Azure <releng-azure@FreeBSD.org>
Контакт: Wei Hu <whu@FreeBSD.org>, <weh@microsoft.com>
Контакт: Li-Wen Hsu <lwhsu@FreeBSD.org>

Публикация образа 15.1-RELEASE в Azure Marketplace находится в процессе. Ожидается, что он станет общедоступным в начале третьего квартала.

Li-Wen изучает технические детали, необходимые для поддержки Azure Trusted Launch.

Wei и Li-Wen совместно с другими инженерами Microsoft исследуют проблему, из-за которой mana(4) некорректно работает на Azure-виртуальных машинах на базе AMD. Устройство mana(4) присутствует на новейших виртуальных машинах Azure седьмого поколения.

Задачи в процессе выполнения:

  • Автоматизация процесса публикации образов и интеграция его в src/release/.

  • Улучшение процесса публикации в Azure Marketplace.

  • Поддержка FreeBSD в утилитах для виртуальных машин Azure.

Открытые задачи:

  • Обновление документации, связанной с FreeBSD, на Microsoft Learn.

  • Обновление пакета sysutils/azure-agent до последней версии.

  • Перенос локальных изменений агента Azure в основной репозиторий.

  • Перенос расширений для виртуальных машин Linux в Azure.

  • Добавление поддержки FreeBSD в Azure Pipelines.

    • https://github.com/microsoft/azure-pipelines-agent/pull/3266

    • Сборка и публикация снимков сборок (snapshot builds) в сообщество Azure.

Спонсор: The FreeBSD Foundation за всё остальное

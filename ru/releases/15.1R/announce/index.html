Дата: June 16, 2026

Команда подготовки релизов FreeBSD с удовольствием сообщает о доступности FreeBSD 15.1-RELEASE. Это второй релиз ветки stable/15.

Некоторые из основных новшеств:

  • Драйверы iwlwifi(4) и другие драйверы беспроводных сетей на основе LinuxKPI теперь базируются на Linux v7.0.

  • Образы FreeBSD для облачных сред, использующие пакетные базовые системы, теперь включают pkg(8) и поддерживают автоматическое обновление пакетов базовой системы при первой загрузке.

  • Новый параметр ядра kern.sched.name позволяет выбирать планировщик ядра во время загрузки.

  • Достигнут значительный прогресс в обеспечении полноценной поддержки версии C23 языка программирования C.

  • Поддержка Unicode обновлена до версии Unicode 17.0.0 и CLDR 48, добавлено 4 803 символа.

Полный список новых возможностей, поддерживаемого оборудования и известных проблем приведён в онлайн-версиях примечаний к выпуску, примечаний по совместимости с оборудованием и списка ошибок, доступных по адресам:

  • https://www.freebsd.msk.ru/ru/releases/15.1R/relnotes/

  • https://www.freebsd.msk.ru/ru/releases/15.1R/hardware/

  • https://www.freebsd.msk.ru/ru/releases/15.1R/errata/

Дополнительную информацию о работах по подготовке релизов FreeBSD можно найти на странице:

  • https://www.freebsd.msk.ru/ru/releng/

Посвящение

Проект FreeBSD посвящает выпуск FreeBSD 15.1-RELEASE памяти Питера Г. Ноймана, давнего коллеги разработчиков FreeBSD в области безопасности на основе мандатного управления доступом, а также человека, который благодаря своему вкладу в такие исторические проекты, как Multics, заложил многие из центральных концепций безопасности операционных систем, которые сегодня воспринимаются как само собой разумеющиеся.

Доступность

FreeBSD 15.1-RELEASE теперь доступна для архитектур amd64, aarch64, armv7, powerpc64, powerpc64le и riscv64.

FreeBSD 15.1-RELEASE может быть установлена с загрузочных ISO-образов или по сети. Некоторые архитектуры также поддерживают установку с USB-флеш-накопителя. Необходимые файлы можно загрузить, как описано ниже.

Контрольные суммы SHA512 и SHA256 для образов ISO, флеш-накопителей и SD-карт включены в конец этого сообщения.

Контрольные суммы для образов релиза, подписанные PGP, также доступны по адресу:

  • https://www.freebsd.msk.ru/ru/releases/15.1R/signatures/

Подписанная PGP версия данного объявления доступна по адресу:

  • https://www.freebsd.msk.ru/releases/15.1R/announce.asc

Назначение образов, предоставляемых в составе релиза, следующее:

dvd1

Содержит всё необходимое для установки базовой операционной системы FreeBSD, документацию, отладочные дистрибутивные наборы и небольшой набор предварительно собранных пакетов, предназначенных для запуска графической рабочей станции. Также поддерживает загрузку в режиме восстановления "livefs". Этого должно быть достаточно, если вы можете записывать и использовать носители размером DVD.

Кроме того, этот образ может быть записан на USB-флеш-накопитель для архитектуры amd64 и использован для установки на машинах, способных загружаться с USB-накопителей. Он также поддерживает загрузку в режиме восстановления "livefs".

В качестве примера использования образа dvd1, в предположении, что USB-накопитель отображается как /dev/da0 на вашей машине, должно работать примерно следующее:

# dd if=FreeBSD-15.1-RELEASE-amd64-dvd1.iso \
    of=/dev/da0 bs=1m conv=sync

Будьте внимательны и убедитесь, что правильно указали целевое устройство (of=).

disc1

Содержит базовую операционную систему FreeBSD. Также поддерживает загрузку в режиме восстановления "livefs". Предварительно собранных сторонних пакетов нет.

Кроме того, этот образ может быть записан на USB-флеш-накопитель для архитектуры amd64 и использован для установки на машинах, способных загружаться с USB-накопителей. Он также поддерживает загрузку в режиме восстановления "livefs".

В качестве примера использования образа disc1, в предположении, что USB-накопитель отображается как /dev/da0 на вашей машине, должно работать примерно следующее:

    of=/dev/da0 bs=1m conv=sync

Будьте внимательны и убедитесь, что правильно указали целевое устройство (of=).

bootonly

Поддерживает загрузку машины с привода CDROM, но не содержит дистрибутивных наборов для установки FreeBSD непосредственно с CD. Вам потребуется выполнить установку по сети (например, с HTTP- или FTP-сервера) после загрузки с CD.

Кроме того, этот образ может быть записан на USB-флеш-накопитель для архитектуры amd64 и использован для установки на машинах, способных загружаться с USB-накопителей. Он также поддерживает загрузку в режиме восстановления "livefs". Предварительно собранных пакетов нет.

Будьте внимательны и убедитесь, что правильно указали целевое устройство (of=).

memstick

Этот образ может быть записан на USB-флеш-накопитель и использован для установки на машинах, способных загружаться с USB-накопителей. Также поддерживает загрузку в режиме восстановления "livefs". Предварительно собранных сторонних пакетов нет.

mini-memstick

Этот образ может быть записан на USB-флеш-накопитель и использован для загрузки машины, но не содержит дистрибутивных наборов на самом носителе, аналогично образу bootonly. Также поддерживает загрузку в режиме восстановления "livefs". Предварительно собранных пакетов нет.

FreeBSD/arm SD card images

Эти образы могут быть записаны на SD-карту и использованы для загрузки поддерживаемой системы arm. Образ SD-карты содержит полную установку FreeBSD и может быть установлен на SD-карты размером от 5 ГБ.

Для удобства тех, у кого нет консольного доступа к системе, пользователь freebsd с паролем freebsd доступен по умолчанию для доступа через ssh(1). Кроме того, пароль пользователя root установлен как root; настоятельно рекомендуется изменить пароли для обоих пользователей после получения доступа к системе.

Для записи образа FreeBSD/arm на SD-карту используйте утилиту dd(1), заменив KERNEL на соответствующее имя конфигурации ядра для системы.

# dd if=FreeBSD-15.1-RELEASE-arm64-aarch64-RPI.img \
    of=/dev/da0 bs=1m conv=sync

Будьте внимательны и убедитесь, что правильно указали целевое устройство (of=).

Предварительно установленные образы виртуальных машин также доступны для архитектур amd64 (x86_64), i386 (x86_32), AArch64 (arm64) и RISCV (riscv64) в форматах образов дисков QCOW2, VHD и VMDK, а также в виде неформатированных (raw) образов.

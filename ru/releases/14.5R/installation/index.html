Краткое содержание

Эта статья содержит краткие инструкции по установке FreeBSD 14.5-RELEASE и обновлению систем, работающих под управлением предыдущих релизов.

Содержание

  • Установка FreeBSD

  • Обновление FreeBSD

Установка FreeBSD

Глава Установка FreeBSD Руководства FreeBSD предоставляет более подробную информацию о самой программе установки, включая пошаговое руководство со снимками экранов.

Обновление FreeBSD

Если вы обновляетесь с предыдущего релиза FreeBSD, пожалуйста, внимательно прочитайте раздел об обновлении в Информации о релизе для ознакомления с важными несовместимостями.

Обновление из исходного кода

Процедура обновления на основе исходного кода описана в главе Руководства Обновление FreeBSD из исходного кода.

Для Git используйте ветку releng/14.5, где будут применяться будущие рекомендации по безопасности или уведомления об ошибках.

Обновление с помощью "FreeBSD Update"

Утилита freebsd-update(8) поддерживает бинарные обновления систем amd64 и arm64, работающих на предыдущих релизах FreeBSD. Системы, работающие под управлением 14.4-RELEASE, могут быть обновлены следующим образом:

# freebsd-update fetch
# freebsd-update install

Теперь утилита freebsd-update(8) может получать компоненты, относящиеся к 14.5-RELEASE. В ходе этого процесса freebsd-update(8) попросит помощи в слиянии конфигурационных файлов.

# freebsd-update upgrade -r 14.5-RELEASE
# freebsd-update install

Теперь система должна быть перезапущена с новым установленным ядром перед обновлением компонентов, не относящихся к ядру.

# shutdown -r now

После перезагрузки необходимо снова запустить freebsd-update(8) для установки новых компонентов пользовательского пространства:

# freebsd-update install

На этом этапе пользователям систем, обновляемых с более ранних выпусков FreeBSD, будет предложено пересобрать или переустановить все сторонние приложения (например, порты, установленные из дерева портов, или пакеты, установленные с помощью pkg(8)) из-за обновлений в системных библиотеках.

После обновления установленных сторонних приложений (и снова, только если freebsd-update(8) вывел сообщение, указывающее на необходимость этого), запустите freebsd-update(8) снова, чтобы он мог удалить старые (больше не используемые) системные библиотеки:

# freebsd-update install

Наконец, выполните перезапуск для загрузки полноценной системы 14.5-RELEASE:

# shutdown -r now
